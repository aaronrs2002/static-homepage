#Custom Homepage

Details: 
A personalized homepage application that brings together news, videos, and weather in one place. 
It has an RSS service built with PHP and is also powered by the YouTube API and a weather API, it has a calendar, 
it supports multiple Bootswatch themes and a fully responsive design for all devices. Users can create and filter custom links, 
run quick searches into Rotten Tomatoes or Wikipedia results, and manage content through a lightweight CMS. 
The app requires no login—data is stored locally in the browser, with options to download or upload for easy backup and transfer.
